# Security policy

Verbose Fortnight uses deliberately vulnerable, **fictional code examples** for education and verification. Do not deploy challenge code to production, use live customer data, or run tests against systems you do not own or have explicit permission to test.

If you find a vulnerability in the **project tooling or repository configuration** (rather than one of the intentionally vulnerable challenges), please do not publish an exploit or sensitive details in a public issue. Contact the repository maintainer privately using GitHub's private vulnerability reporting feature, if enabled.

This project is not a security certification or a substitute for professional security review.
